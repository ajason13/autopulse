## The AutoPulse Mission

AutoPulse is an educational, offline-first framework for validating and replaying read-only telemetry. ICE analysis uses fixed heuristics and in-memory rolling statistics. Learned healthy-baseline training and persistence and calibrated failure prediction are not implemented. Vehicle diagnostic accuracy and warning lead time before DTCs have not been established.

Read the [validation evidence and limitations](reference/empirical-validation/) before interpreting scores. EV support is limited to validation, routing, replay, adapter guardrails, and event serialization; it includes no EV anomaly scoring or live capture.

<CardGrid stagger>
	<Card title="Read-Only Scope" icon="approve-check">
		Offline inputs use hashed vehicle identifiers. Write, actuation, and ECU configuration behavior is outside the project scope.
	</Card>
	<Card title="Statistical PdM" icon="random">
		Explore **HDF** and **OSF** experimental branches. Their labels and scores do not establish vehicle faults or failure likelihood.
	</Card>
	<Card title="Temporal Precision" icon="list-format">
		Rolling statistics use 60 samples by default. OSF separately tracks exposure over 60 seconds; sampling cadence changes the statistics window duration.
	</Card>
	<Card title="Codex Review" icon="document">
		One Codex session owns a focused change. Risk-sensitive changes receive a fresh-context Codex review under current repository instructions.
	</Card>
</CardGrid>
