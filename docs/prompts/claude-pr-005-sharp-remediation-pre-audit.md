You are AutoPulse's independent Lead Auditor (Claude Sonnet 4.6). Review this
**pre-implementation** remediation plan for findings F-01 through F-03 from
the rejected PR-005 evidence exercise. Return exactly one: **NO BLOCKERS**,

authorizes no tag, release, publication, deployment, or RC identifier.

## Why this is a new gate

The prior evidence label `v0.1.0-rc.1` / commit
`81a157927fcacf4ae47716326885d12477e0002d` is permanently retired. It must
not be reused. At that commit, `grubby-galaxy/package.json` directly declares
`"sharp": "^0.34.5"`, and `package-lock.json` resolves `node_modules/sharp`
to `0.34.5`. The prior final audit identified a high-severity advisory for the
affected range `<0.35.0`, with no approved, expiry-dated exception. The
existing docs CI job runs `npm ci`, browser installation, build, smoke, and
e2e; it has no Node dependency vulnerability gate.

Only these files/concerns may change, unless you identify a necessary focused
test or documentation correction:

   direct production dependency `sharp` to `^0.35.3` / resolved `0.35.3` using

## Deliberate residual decision

`--audit-level=high` is intentionally narrower than the Python vulnerability
gate: it blocks the high/critical production dependency category that caused
F-01 without introducing a release gate on lower-severity build-tool churn.
`--omit=dev` intentionally excludes development dependencies. A future
all-dependency audit/report is a separate, non-blocking enhancement; this plan
does not claim the production gate is exhaustive.
