## Scope and prohibited use

AutoPulse is educational, read-only, offline validation, analysis, and replay
for previously supplied local JSON/JSONL/CSV fixtures. It does not connect to a
vehicle, collect telemetry, or need a runtime network. The only installed
command is `autopulse-debug`.

This candidate does not authorize live adapters, vehicle capture, VIN
reads/storage, telemetry upload, road testing, unattended monitoring, DTC
clearing, actuator/control requests, OBD-II/UDS writes, session escalation,
security access, seed/key material, fleet/deployment use, or any write-capable
diagnostic behavior. `autopulse.live` is absent from package artifacts.
