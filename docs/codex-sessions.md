# Codex sessions

Open this repository as the Codex working directory. State one change and its
acceptance criteria. Repository `AGENTS.md` supplies the diagnostic boundaries;
`CONTRIBUTING.md` supplies development setup and verification.

Continue a task with its branch, remaining acceptance criteria, and verification
results. Keep local continuation notes under the Git directory; consult focused
feature documentation for durable decisions instead of rebuilding a shared
active-context file.

The owner maintains additional operator guidance in the `terminal-dotfiles`
repository at `docs/codex-workflow.md`. That guide is optional human reference
material and is not required to contribute to AutoPulse.
